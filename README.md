What is Alpha Recrafted?

Alpha Recrafted is a small project I did as a coding challenge, initially only lasting a week, but eventually being extended further. 
It is a mod for Alpha 1.1.2_01 that implements some new features that fall in-line with Notch's design philosophy during the Alpha phase of the game, and aims to emulate the Seecret Friday style of updates.
Another goal of the mod is to make every item and block obtainable in legit survival, such as snow from outside the snow worlds, hence the addition of "biomes". 
Additionally, it also adds unused content, such as the quiver, as well as quality of life improvements from newer versions, like shift-clicking.


What does Alpha Recrafted add?

Many things. For a full changelog, please refer to the forums post: https://www.minecraftforum.net/forums/mapping-and-modding-java-edition/minecraft-mods/3225486-legacy-alpha-recrafted-a-mod-that-revives-alpha-1

The most prominent features include:
* Biomes: Only two of them exist, deserts and snowy biomes, using the Beta 1.7.3 biome system (without modifying the terrain). The grass does NOT tint!
* Extended world height to 256, backwards compatible with vanilla Alpha worlds!
* Working quivers: They store arrows by clicking on them with arrows, up to 256 at a time. Found exclusively in dungeons.
* Rideable pigs: You can control pigs with an apple on a stick, making them move 50% faster than by foot, as long as you hold the apple on a stick.
* Way to set your spawn point using crying obsidian.
* Fully functioning fishing rods
* Basic weather for renewable snow in snowy biomes
* Better dungeon loot
* Made everything obtainable in survival (e.g. apples now drop rarely from leaves, gold tools have silk touch etc.)
* Creative mode, with working inventory from Beta 1.8
* New world generation options: Infdev 415 terrain (with caves), 2d perlin terrain from Infdev 227, unused floating island terrain restored and superflat.
* New world themes: Winter (now selectable rather than random), Hell, Paradise, Woods and Desert.
* Improvements to zombies. They can now spawn wearing armor, and each zombie holds a random tool, which determines what item it drops, to make them more useful.
* Craftible colored wool and bricks
* Vertical slabs
* LOTS of quality of life improvements


How do I install Alpha Recrafted?

The easiest way is through MultiMC: 
* Download any version of your choice (I always recommend the latest, or v1.1.3_02 if you want the most vanilla experience with just the quality of life stuff)
* Make a new Alpha 1.1.2_01 instance in MultiMC
* Click "Edit instance"
* Go to the "Version" tab
* Click on "Add to jar" on the right-hand ribbon and select the jar you just downloaded
* Make sure you put the following in JVM arguments while still in the version tab: -Djava.util.Arrays.useLegacyMergeSort=true


Will this mod receive more updates in the future?

No, I have no plans to keep updating this mod, as I feel like I have done enough to improve the core gameplay, whilst keeping it intact. Anything more that I add could very well become "bloat".
